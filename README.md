omnicost(CRUD)

Aplicação web de controle de gastos que implementa as operações CRUD
(Create, Read, Update, Delete), com persistência via localStorage
e cálculo automático do total.

## Funcionalidades
- Adicionar gastos com descrição, valor e categoria (Create)
- Listar gastos salvos (Read)
- Editar descrição e valor de um gasto (Update)
- Excluir gastos (Delete)
- Exibir o total gasto, formatado em R$ (pt-BR)
- Persistência dos dados ao recarregar a página

## Tecnologias
- HTML5
- CSS3
- JavaScript (vanilla)

## Como rodar
Abra o arquivo `index.html` no navegador.
